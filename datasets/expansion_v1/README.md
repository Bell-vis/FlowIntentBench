# Case definitions

This directory contains 96 cases in 24 families, each with O1–F1, O2–F1, O3–F1, and O1–F2 conditions. `candidate_cases/` contains 68 constructed cases and `reference_cases/` contains the 28 retained cases. These are one benchmark membership, not separate evaluation pools.

Use the [evaluation manifest](../../experiments/expansion_v1_development/case_manifest.json) for evaluation and the [repository README](../../README.md) for installation and commands. `execution_evidence/` supplies frozen numerical construction evidence. Historical model runs and construction review outputs are not distributed. Original development/calibration flags are preserved.
